## Completed findings

- Measured equal-size menus: 300 doublets across 100 hosts, with 224 active assays and 26 hosts whose three doublets differ in binary activity. The repaired score selected an active option for 78/100 hosts, compared with expected uniform activity 0.746667. The gain was 0.033333 (paired host-cluster 95% interval -0.029725 to 0.085719); it does not establish an improvement. The parent triplets were externally selected; this is not arbitrary cocktail design or a new independent cohort.
- Fixed-composition host discrimination: only three of 18 compositions contain both classes. Repaired conditional pair-weighted AUROC is 0.720930; the host-cluster interval is 0.522914–0.875000, but the crossed host/composition interval is 0.250000–0.940000. Shared phages remain part of a fixed bank, not independent bank replication.
- StaphStudy second-source analysis: 1,053 input pairs, canonical 8 phage/26 host clusters, four eligible blocks and 200 evaluated test pairs. Full-model mean pooled AUROC changes from 0.619926 with shared entities to 0.376302 with dual exclusion; macro-fold AUROC changes from 0.668245 to 0.558346. Intermediate regimes are not monotonically ordered. Phage-only pooled and within-fold trends disagree, and the training-prior control has pooled AUROC 0.322495 despite within-fold AUROC 0.500. This is a retrospective within-source refit, not new frozen cross-source validation.
- Fresh nested comparison with identical 448-feature inputs: GBM/MLP host-exclusion AUROC 0.935105/0.891437 and dual-exclusion AUROC 0.763409/0.723116. Three candidates per family and identical grouped inner splits were used. All 100 MLP fits reached the declared 150-epoch budget; optimal convergence or exhaustive search is not claimed. This does not reconstruct the historical model-selection rationale.

## MLP optimization-budget sensitivity

A prewritten retrospective amendment retained the same grouped splits and three neural candidates, allowing at most 1,000 epochs with training-loss stopping (no random validation). MLP AUROC was 0.881621 for host exclusion and 0.712765 for dual exclusion. The 10 additional outer models and all traces are included. Observed epochs ranged from 64 to 437; 0 of 100 fits reached the new cap. The initial 150-epoch results remain unchanged. A documented CSV-verification tolerance repair changed no fit or score. This is an optimization sensitivity on already accessed outcomes, not exhaustive tuning or fresh external validation.

## Float32 inference portability

The default saved-model replay retains the original strict tolerances. The explicit command `python -B scripts/frontiers_strengthening_2026_10_16/verify_extension_analysis.py --portable-float32` additionally supports float32 MLP inference across platforms. After complete 174-model/42-pooled-group Windows/Linux diagnostics, an empirical engineering cap of 32 float32 machine epsilons was adopted for neural probabilities only; this is not a formal roundoff bound or a statistical test. All fold/pooled AUROCs must agree within 1e-12, AP within 1e-7, Brier/ECE within 32 epsilons, with unchanged 0.5 decisions, positive-negative order/ties and audited top-k sets. Source/model/data hashes, tree predictions, scalers, split and entity-control checks remain strict. Observed Linux score differences were at most 0.00000230; maximum pooled AP difference was 0.000000026. Isolated same-label pooled tie/order changes are counted and disclosed rather than interpreted as changed discrimination. No AUROC or 0.5 decision changed. Original CSV scores and reported scientific results remain unchanged. Runtime-factor causation was not isolated. Use the diagnostic command separately to inspect differences; a diagnostic report is not itself a pass.
